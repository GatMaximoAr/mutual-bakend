#  Mutual backend

## Description 

Este proyecto tiene por fin servir como ejemplo practico de habilidades en desarrollo aplicadas a un modelo de negocio, una tienda con sistema de socios con beneficios, no descarto que en el futuro sea aplicable a la vida real.


## Caracteristicas

- [ ] manejo de inventario
- [ ] manejo de ventas y emision de tickets
- [ ] manejo de socios
- [ ] sistema de usarios y validacion
